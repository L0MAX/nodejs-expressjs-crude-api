# Code Raccoon

nodejs-expressjs-crude-api is a simple Node.js application that demonstrates basic CRUD operations using Express.js. This project showcases building RESTful APIs with Node.js and Express.

## Project Structure

- `index.js`: The main entry point of the application.
- `package.json`: Contains the project metadata and dependencies.
- `routes/users.js`: Defines the routes for user-related operations.
- `users.json`: A sample JSON file containing user data.

## Features

- List all users
- Create a new user
- Get a specific user by ID
- Update a user by ID
- Delete a user by ID

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/your-username/code-raccoon.git
    cd code-raccoon
    ```

2. Install the dependencies:
    ```sh
    npm install
    ```

### The server will be running on http://localhost:5000.

API Endpoints
GET /users: List all users
POST /users: Create a new user
GET /users/:id: Get a specific user by ID
PATCH /users/:id: Update a user by ID
DELETE /users/:id: Delete a user by ID
